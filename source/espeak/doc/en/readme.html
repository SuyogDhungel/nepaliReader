Nepali eSpeak

Nepali eSpeak is NVDA's eSpeak NG with Nepali Reader built in. There is nothing to switch on or off.

Getting started

Choose it once: NVDA menu, Preferences, Settings, Speech, Synthesizer: Nepali eSpeak. Its voice, rate and pitch are set there as for eSpeak NG. The voice can be English or Nepali: with an English voice, Nepali text is read in the Nepali voice; with the Nepali voice, English text is read in the English voice. A number or a sign on its own is read in the language of the voice.

Everywhere: the right voice

Nepali (Devanagari) text is read in the Nepali voice and English text in the English voice, in the same sentence, in web pages, apps and NVDA's own menus. A web page does not need to say its text is Nepali (lang="ne"). A page that says its Devanagari text is Hindi is read in Hindi. Numbers and signs are read in the language of the words beside them. Nothing in a web page or an app is changed: its Unicode is already right, and Preeti is not used there.

PDF files: the real text

In a PDF (Chrome, Edge, Brave, Acrobat and other PDF readers), text in Preeti and similar fonts and Nepali text whose Unicode the PDF stores damaged are read as the real Nepali text, rebuilt from the PDF file itself. Headings, tables and formatting are reported where they are on the page; NVDA's table keys and quick navigation (T, H) work; Ctrl+C copies the real text, and a table as a table.

Word: Preeti

In Microsoft Word, text in Preeti and similar fonts is read as Nepali. Unicode Nepali typed in Word is read as it is.

Nepali Reader add-on

Nepali eSpeak contains Nepali Reader. If the separate Nepali Reader add-on is also installed, that add-on reads PDFs and Word documents (with its own settings and its Nepali mode key) and Nepali eSpeak only switches the voice. Remove the separate add-on to have nothing to switch.
